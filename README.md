# Hedgehog 语感词库

自用多语言语感学习站（原名复刻自对语感词典类产品形态的模仿，内容全部原创）。
纯静态 + 浏览器端加密，无后端、无框架、无构建工具。

## 特性

- **密码门**：内容以 AES-GCM 加密上传（`data/words.enc`），浏览器 PBKDF2 解密，仓库里没有明文数据
- **三语词库**：雅思英语 / TOPIK 韩语 / JLPT 日语核心词 + **6 大场景厅 72 词**（教育/科技/环境/健康/旅行/工作），词条 = 词感直觉 / 中式误区 / 高频搭配 / 原创例句
- **语感宫殿（记忆宫殿学习模式）**：首页 = 宫殿总图（场景 = 房间，掌握 = 点灯）；房间带展位号与陈设钩子；背词 = 巡游（小地图站点 + 桩位 + 整厅点灯）；词详情带宫殿地址
- **三张基础表**：词根词缀（51 词根·41 前缀·33 后缀）、한글 音表（元音辅音收音 + 8 条音变规则）、五十音（全表 + 浊音拗音 + 6 条节奏规则）
- **语法翼楼**：英语 6 宫室 30 语法点全原创（走廊总览 + 折叠点卡：语感/公式/例句/误区）
- **记忆钩子 + 构词解剖 + 造句本**：每词画面钩子与谐音助记（102 条）；自动解剖词内语素（trans-+port）；本地造句本（费曼输出）
- **巡游（背词的宫殿化）**：选厅出发（每轮 10 站），认卡 / 拼写（键盘凭记忆拼）/ 书写（**手写板凭记忆写 → 与答案并排比对 → 自评**）；**间隔重复**：模糊词按 1/3/7/15 天自动回访，「今日复习」队列 + 房间 ↻ 角标；**串门混考**交错练习；**本周打卡格**；**练字本**（触控画板贴图册，本机存 20 张）；进度全存本机 localStorage
- **收藏**：本机 localStorage；**跨语言搜索**：三语通查带语言标签；TTS 按语言发音
- **韩系 감성 本子风 UI**：整站是一本活页本（螺旋线圈 + 活页孔 + 页边线 + 右缘索引标签导航 + 动态日期页眉 + 「换纸」彩蛋[方格/横线/空白] + 页码）；灰绿/雾粉/陶土低饱和色板、细线插画刺猬（坐姿看书）、细线 SVG 图标（无 emoji）
- **PWA**：手机可"添加到主屏幕"；响应式，国内手机/电脑直接访问（系统字体，无外部资源请求）

## 修改内容（词库或基础表）

```bash
# 1. 编辑 src/words-*.json（词库）或 src/tables-*.json（基础表）
# 2. 合并 + 重新加密（密码不入库：见本地 PRIVATE-NOTE.md 或私聊会话）
node tools/encrypt.js <密码>
node tools/encrypt.js <密码> --verify   # 校验（会打印各词库词数与表节数）
# 3. commit（src/ 被 gitignore，只会提交 words.enc）
```

**换密码**：重新执行第 2 步换新密码即可（salt 不变），告诉所有设备用新密码。
