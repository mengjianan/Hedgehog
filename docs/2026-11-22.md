### 首页布局整改·第 1 步：结构与位移

**用户要求**：首页「布局不好看、布局有些问题」，装排版审查 skill 后按报告整改；本步只做结构与位移，不改字号（风险最低、对「看着不对劲」收益最大）。

**体检基线**（`layout-discipline` 的 `check_layout.py`）：467 处违规、26 个字号、251 处非 4 倍间距、13 种圆角、`:`root` 外 104 处裸 hex、页面左右留白 78/30 不对称、`overflow:hidden` 有裁切风险、781–1023px 六列词厅被挤。

**改动**：

- `styles.css`
  - `.page` 内边距 `20px 80px 56px 80px`（原左右 78/30 不对称，改为等宽留白）
  - `.holes` 左 20px、`.page::before` 左 56px — 与新的左留白对齐，装订孔不再压在文字上
  - `.results:empty { display:none }` — 空结果区不再占位，首页块与块之间不再凭空多一段空隙
  - `body.home-view .view` 补 `flex:1; width:100%; max-width:1040px` — **根因**：`.page` 在首页是 `flex-column`，基类 `.view` 的 `margin:0 auto` 会取消交叉轴 stretch，导致 `.view` 变成 fit-content（实测 954px），所有首页块比纸面内容框窄 159px，右侧齐不齐全靠运气。显式给宽后全栈统一左右边界
  - 首页块节奏回归 4px 栅格：`body.home-view .data-row { margin-top:16px; gap:10px }`、`body.home-view .home-stat { margin-top:8px }`（移动端降为 8px / 4px）
  - 新增 `@media (min-width:781px) and (max-width:1023px)`：词厅 6 列 → 3 列，平板宽度不再挤成面条
  - `@media (max-height:720px)` 与 `body.home-view.has-results`：`.page` 允许纵向滚动、`.view` 改为 `flex-start`，矮屏和出搜索结果时不再被 `overflow:hidden` 切掉底部。**这两块必须排在移动端块之后**——移动端把 `.page` 锁成 `overflow:hidden` + `space-evenly`，写在前面会被盖掉
- `app.js`
  - `viewHome()` 顺序改为 hero → 搜索结果 → 学习进度 → 词厅 → 数据行 → 统计 → 脚注；搜索结果紧贴搜索框，出现时即时可见
  - `renderResults()` 给 `body` 切 `has-results` 类；路由离开首页时移除，非首页样式不受影响
- `index.html`：`styles.css?v=40`、`app.js?v=40`
- `sw.js`：`CACHE = 'hedgehog-v40'`
