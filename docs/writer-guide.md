# 韩语词条写手指南（TOPIK 韩语核心词 topik-core）

你是「TOPIK 韩语核心词」的词条写手。本文档是唯一标准，严格遵守。

## 输入与输出

- **输入**：种子 JSON（路径由任务给出），数组，每项含 `w/pos/hanja/gloss(短释义)`。**顺序照抄，一条不换不漏。**
- **输出两个文件**（路径由任务给出）：
  1. words 文件：`{"id": "topik-core", "lang": "ko", "title": "TOPIK 韩语核心词", "speech": "ko-KR", "words": [ ...N 条... ]}`
  2. hooks 文件：`{"hooks": {"topik-core/词形": {"img": "画面", "mn": "助记"}}}`

**写入策略（防拦截防空转）**：words 文件先 Write 前一半（含头字段），再 Edit 追加后一半；hooks 文件较小可一次写。

## 词条字段

| 字段 | 要求 |
|---|---|
| w | 词形，照抄 한글 |
| pron | 罗马音（Revised Romanization，纯小写无空格，如 `gongbu`） |
| pos | 명사→n.、동사→v.、형용사→adj.、부사→adv.、대명사→pron.、수사→num.、감탄사→intj.、관형사→det.；多词性写 `n./v.` 形式 |
| zh | 2-4 个中文义项，**分号**分隔（从韩语释义转译，地道简体中文） |
| sense | 词感，**≤150 字符**，见下 |
| trap | 中文母语者专属易错点，**≤50 字符** |
| collo | 恰好 3 个常用搭配（字符串数组） |
| ex | 1-2 个 `{en: 韩文句子, zh: 中文翻译}`，en 必须纯韩文，难度贴 TOPIK 中급 |

## 词感标准（sense ≤150 字符，四要素至少占两项）

1. **破意象/语感直觉**——一句话说清"用它的感觉"
2. **边界或近义辨析**——它不是什么 / 和近义词差在哪（含与中文的差异）
3. **搭配内嵌**——写进句子自然带出，不罗列
4. **语体或母语者反应**——写作提醒 / 母语者反应

**汉字词重点**：有 hanja 的优先走「한자어 秒懂」——如 공부=工夫，但语义收窄为读书学习，中文「下功夫」不能直译。

金标准样例（控制在 ≤150 字内仿写）：
- 공부——汉字词「工夫」的对应词，但语义收窄到正经读书学习。上课、自习、备考都说 공부해요；打游戏练级不算，那叫 연습하다。
- enhance（英语库佳例）：让已经存在的东西变得更好：enhance credibility。它不含「从无到有」，所以不能说 enhance a brand-new program。是 improve 的高级替换，但别一篇用三次。

**禁**：「XX类核心：」「两义：①…②…。」清单体、场景标签开头。

## 钩子规则（选择性，宁缺毋滥）

- **给钩子**：汉字词同形异义/语义收窄、同形多义、外来语陷阱、近义辨析、核心多义词、自他动词配对
- **不给钩子**：简单直白词、与中文完全对应的透明汉字词
- 数量：约词数的 25%~50%，宁少勿滥
- img：一幅可想象的具体画面（中文）；mn：专治中文母语者的坑（点破同形异义/词源/谐音）
- key 必须是 `topik-core/该批词形`

金标准钩子：`topik-core/공부 → {"img": "深夜图书馆亮着的一盏灯", "mn": "工夫 = 공부，汉字词秒懂"}`

## 硬性要求

1. 条目数与顺序与种子完全一致；钩子 key 全部命中本批词形
2. zh/sense/trap 为简体中文；例句 en 纯韩文
3. **写完直接交报告，不做自查**（结构由主控四查兜底；若自己发现写错可顺手改，但禁止写自查脚本、禁止反复空转）
4. 报告格式（一行）：`条数 N / 钩子 N`
