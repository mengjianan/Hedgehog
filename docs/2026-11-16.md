### 基础表「顺序播放」按钮（`见 commit`）

- **用户要求**：三个基础表的 [抄写] 旁加播放按钮——按顺序自动播音，一个音读两遍、音间隔 2 秒；再点暂停、再点继续
- **实现**：
  - `viewTable` 的 `.table-actions` 加 [▶播放/⏸暂停/▶继续] 按钮（`ICON.pause` 新增细线暂停图标），三态标签 `tblPlayBtnHTML()`
  - 播放器 `tblPlay`：收集页内 `.table-section [data-say]` 按 DOM 顺序连播（五十音清音→浊音→拗音 / 韩语音表字母+名称 / 词根→前缀→后缀）
  - 节奏：每个音播完（或失败）→ 等 2 秒 → 下一遍/下一个；`ended/error/play拒绝` 三路 `settle()` 互斥收口；有道源失败转系统 TTS（`tblPlayTTS` 按 le 选 ja/ko/en 语音），不刷 toast
  - 暂停 = 掐计时器 + 掐当前音；继续 = 从当前（第几个/第几遍）状态重进 `tblPlayStep()`；播完自动复位 + toast「播放完毕」
  - **离开本表自动停**：`route()` 里 `location.hash !== '#/tables/' + tid` 即 `tblPlayStop()`（换页/换表/进练习都停）
  - 词根表 `morph-form` 补 `data-say/data-le`：顺带获得「点词根发音」（与另两表点格子发音一致）
