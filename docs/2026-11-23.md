## 今日进度

### 日用角·对话：三语发音（已完成并验证）

- **用户反馈**：背词 → 日用角 → 对话，只有英语能播，日语、韩语没有发音
- **原因**：
  - `viewDailyDlg()` 每句只渲染一个喇叭，`data-act="dlg-say"` 不带语种
  - 事件分支 `act === 'dlg-say'` 写死 `dln.en`
  - 底部「听整段」`dlgSayAll()` 只排队 `ln.en`，且用写死 `en-US` 的 `ttsUtter()`
  - 数据侧无缺口：`data/dialogues.json` 61 段 272 句，en/ja/ko/zh 四语齐全，缺 0
- **改法**：
  - 每句气泡外侧竖排 英/日/韩 三个小按钮，`data-lang` 区分语种；B 句（右对齐）键落在气泡左侧
  - 事件层加 `dlgLineSay(ln, lang)`：按语种取译文，有道 `le=jap`/`ko`，失败转对应 `ja-JP`/`ko-KR` 系统 TTS
  - `dlgSayAll(d, lang)` 收语种重写：按语种顺序逐句连播，单条有道路径失败立刻转 TTS 念完再进下一句；开播先 `speechSynthesis.cancel()` 掐掉上一轮
  - 移除只剩英语用的 `ttsUtter()`
  - `styles.css` 新增 `.dlg-says`（竖排键列）、`.dlg-playall`（整段按钮行），去掉旧的 `.dlg-line .mini-btn`
  - `index.html` 与 `sw.js` 缓存戳进 v41
